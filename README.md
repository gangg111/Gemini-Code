\# Gemini-Code
An advanced agentic tool leveraging the power of Gemini models within your development environment.

\## 🚀 Installation
1\. Clone the repository: `git clone https://github.com/gangg111/Gemini-Code.git`
2\. Install dependencies: `pip install -r requirements.txt`
3\. Configure OAuth 2.0 according to the documentation.

\## 🔑 Authorization
This project uses Google OAuth 2.0. Upon the first execution, a `token.json` file will be generated, enabling secure access to your resources without the need for repeated login.
